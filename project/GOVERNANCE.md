# Project Governance

## Project Classification

Mettelo Project Studio — simulated confidential-client engagement.

## Client Representation

The confidential client is simulated.

Participants must not claim:

- employment by the simulated client;
- access to a real confidential energy client;
- that the public smart-meter dataset is private Mettelo client data;
- that Mettelo has an undisclosed external relationship represented by this project.

Participants may accurately describe verified participation in Mettelo Project Studio.

## Data Attribution

The underlying smart-meter dataset is published by UK Power Networks through the London Datastore under a Creative Commons Attribution licence.

Teams must retain appropriate attribution.

## Responsible Analytics

Teams must:

- avoid unsupported causal claims;
- distinguish tariff association from proven treatment effect;
- document sampling and historical limitations;
- avoid attempting to identify households;
- report uncertainty;
- avoid recommendations that overstate the evidence.

## GitHub Security

Never commit:
- passwords;
- API keys;
- access tokens;
- private credentials;
- personal data not intended for publication.

## Verification

Mettelo may review commits, issues, pull requests, reviews, documents, code, analytical artefacts and presentation evidence to verify participation and contribution.
